# Scripts (Stage 4)

Animation scripts, one file per episode, in the format described in each script's
"Script Key". Scripts follow the approved episode list in `season/episode-list.md` and the
pilot outline in `season/pilot-outline.md`.

## Format

- Scene headings (`INT.` / `EXT.`, place, time of day)
- *Action lines* in italics
- Character names in bold caps, with a short `(parenthetical)` for how a line is said
- `[CLUE ALERT #n, 1st/2nd]`, `[CHANT]` and `[JOURNAL]` cues
- `ANIMATOR:` notes for visual direction
- `⚠️ FLAG` notes for anything that might be too scary or too complex, with the fix built in
- A script-notes section at the end: timing guide, clue tracker, flag summary and questions
  for the producer

## Writing rules

1. Short sentences, rhythm, repetition. Read it aloud.
2. Every clue appears twice, with a Clue Alert both times, before the reveal.
3. Three clues, one red herring.
4. Nobody is shamed. The culprit is always met with kindness.
5. The lesson is shown first and said once, by a kid, in kid words.
6. Moony is silhouetted (with a floppy ear and a wagging tail) until the pilot's reveal, and
   is cleared in every episode.
