# Storyboards and Shot Lists (Stage 5)

Camera, staging and timing plans for animators. Stage 5 turns the approved scripts in
`scripts/` into shot lists and storyboard panels.

## What is in this folder

| File | What it is |
|---|---|
| `shot-language-guide.md` | The series' visual grammar: camera rules, lighting, the Clue Alert and recap shots, sound design cues, accessibility and scare-safe checks. Applies to every episode. |
| `timing-report.md` | Estimated running time of all 13 scripts, where each is long or short, and a recommended trim or pad list |
| `ep01-part1-shot-list.md` | Pilot Part 1 ("The Legend"): a numbered shot list with storyboard panel descriptions, timed to 11:00 |

Still to come, in batches of about three: pilot Part 2, then episodes 2 to 13.

## How to read a shot list

Each scene has a table. One row is one **panel** (a storyboard frame that is also a shot).

| Column | Meaning |
|---|---|
| **Panel** | `P1-07` is Part 1, panel 7. Episode lists use `E02-07` and so on. |
| **Shot** | Size and angle: **WS** wide, **MS** medium, **CU** close-up, **ECU** extreme close-up, **OTS** over the shoulder, **2S** two-shot, **POV** point of view. Angle is *eye* level unless stated. |
| **Move** | **Static**, **push-in**, **pull-out**, **pan**, **track**, **drift** (a slow storybook sway), **cut** |
| **Picture** | What is in frame, and what the animators draw |
| **Sound** | Dialogue (short quote), SFX and music cues |
| **Dur** | Estimated seconds. A scene total is at the bottom of each table |

Cues from the scripts are kept: `[CLUE ALERT #n, 1st/2nd]`, `[CHANT]`, `[JOURNAL]`, and
`ANIMATOR:` notes. Panels marked ⚠️ carry a scare-safe note from the guide.

## What this stage does not do

- It does not produce finished artwork. Panel descriptions are written, not drawn. If useful,
  the next step can add thumbnail drawings for key panels (clue shots, the Moony reveal, the
  recap layout).
- It does not replace an animatic. The timings here are estimates from the scripts. A
  read-aloud animatic with voices will set the real running times.
